OWNER TRANSFER UI POLISH

The transfer table now uses consistent spacing, typography and light amount
badges instead of full-height coloured columns. Return rows are grouped beneath
their transfer, with a subtle green accent and clear status labels. Zero returns
use a neutral badge. Deleted transfers remain visibly red with their reason.
Action buttons share the same size, border and focus treatment. The return popup
uses the same palette and fits mobile screens.

This is a UI patch for the installed Owner Transfer edit/return update.
No database change, terminal command or asset build is needed.

CPANEL FILE MANAGER

   /home/bicpolga/public_html/system.bicpolgahawela.lk/

   resources/views/owner-transfers/index.blade.php
   resources/views/owner-transfers/styles.blade.php

   Preserve the folder and .gitignore.

4. Hard-refresh Owner Bank Transfer.
