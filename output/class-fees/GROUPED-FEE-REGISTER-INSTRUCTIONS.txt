Prepared and verified locally. Upload this ZIP to apply the change online.

1. Back up the existing application files.
2. Upload grouped-fee-register-update.zip to the Laravel application root:
   /home/bicpolga/public_html/system.bicpolgahawela.lk/
   (the folder containing app/, resources/, routes/ and public/).
3. Extract there and overwrite all matching files. Do not extract in public/ alone.
4. In storage/framework/views/, delete only compiled .php files. Preserve the

   because this cumulative package includes the earlier fee routes.
6. Hard refresh the page: Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows).

No terminal command, database migration, SQL import or asset build is required.

  Overview and downloads; payment counts come before fee columns.
